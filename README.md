# 展翼笔记（ZhanyiNotes）

Windows 本地 Markdown 笔记软件：左边写、右边实时看排版。笔记就是磁盘上的 `.md` 文件，Obsidian、VSCode、Typora 都能直接打开，数据永远是你自己的。

**永久免费**：不用注册、不用激活码、没有会员、没有内购，装上就能用。

## 主要功能

- 编辑 / 分栏 / 预览三种视图，`Ctrl+E` 一键切换
- 标签归类、全文搜索、自动保存
- 图片可直接粘进笔记（本地存图，预览显示）
- 登录后多端同步：Windows、网页版、手机端共用同一个笔记库
- 深色主题跟随系统；全部笔记可打包成 ZIP 导出
